- 契约版本：
- 支持的 APP_VERSION / 平台 / 架构：
- 路线：T1 / T2（说明依赖）
- 功能及明确不支持范围：
- 初始化、登录与权限前置条件：
- 材料获取/刷新依赖与每次请求依赖（分别列进程、页面、服务、厂商库）：

## 输入
| 参数 | 类型/编码 | 必选/默认 | 范围 | 来源与生命周期 |
|---|---|---|---|---|
| parameters | 待定义 | 是 | 待定义 | 调用方 |
| context | 会话句柄 | 按需 | 绑定身份与实例 | 不在日志中输出凭据 |
| operation_id | 字符串 | 是 | 唯一标识 | 是否服务端去重须实测 |
| deadline | 待定义 | 是 | 总时限 | 不是取消成功保证 |

## 输出与状态
- succeeded：独立业务证据已确认完成。
- pending：已受理，尚未完成。
- failed：明确失败，说明副作用状态。
- unknown：可能完成，先查询/对账，不盲目重发。
- 错误码：AUTH_REQUIRED / UNSUPPORTED_VERSION / REINITIALIZE_REQUIRED / INVALID_ARGUMENT 等，填真实映射。
