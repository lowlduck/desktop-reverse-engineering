# 12 · 采集器生命周期与失败清理

适用：hook、调试会话、原生回调或辅助进程存在于用户正在使用的桌面进程内。该流程不要求某种工具，也不保证特定目标不会崩溃。

## 安装前

- 固定进程 PID **和创建时间**，防止 PID 复用；核对实际加载模块而非仅核对磁盘上某个同名文件。
- 记录目标存活基线、工具版本、hook 入口、脚本/适配器哈希。已有附加工具及其资源所有者也要列明。
- 使用可读区域与长度上限验证输入；按关联标识只收本次目标数据。入口内不进行业务调用、不修改参数或全局错误状态，除非它正是已授权的实验变量。
- 分离“已安装但暂停”和“正在采样”。为事件数、总字节、单次长度、持续时间设上限，并让丢弃/耗尽可观察；预算耗尽不能报告为完整采样。

## 单一所有者与单一在途操作

同一进程的采集器优先合并为一个会话/脚本；无法合并时指定一个协调者，统一暂停与串行释放。不要让多个控制器同时 teardown 同一目标资源。

每个操作记录名称、UTC 开始/结束、单调时钟开始/结束、返回结果、异常、是否仍在执行。时间超限只是控制器没等到结果，**不表示底层操作已经取消**。

```text
开始操作 → 保留 future/任务句柄
  完成成功 → 保存完成证据 → 才进入下一项
  明确失败 → 保存失败与资源归属 → 按已知恢复方式处理
  等待超时 → 保留同一个在途任务 → 报告 pending/unknown
             不并发提交 unload/detach/重复 attach
```

持续 pending 不等于无限静默等待：让控制通道可读、定期报告状态，在约定观察期限停止后续实验并交付未完成状态。只有工具提供且已验证的取消操作才能当作取消；强杀用户进程不是默认清理方案。

## 停止顺序与完成证据

按所用工具的资源模型调整，通常是：停止接纳新样本 → 等待在途回调/保存队列到安全边界 → detach 自己安装的 hooks → 等待脚本 unload 完成 → 等待 session detach 完成 → 核验目标存活与资源释放。

1. **pause acknowledged**：采样门关闭；保留最后序号和丢弃数。
2. **stop acknowledged**：记录逐个 listener 移除结果与剩余 hook 数；不自动等同于脚本已卸载。
3. **unload completed**：以 API 实际返回/完成事件为准。
4. **detach completed**：保存完成返回、detached 原因及 crash 信息；区分主动 detach 与目标退出。
5. **target health observed**：记录进程身份与存活；若允许，补业务健康检查。进程尚存不证明长期稳定。
6. **storage finalized**：只有不会再有数据写入时关闭输出，记录最终计数及哈希。早到/晚到事件和截断文件不能被吞掉。

某些工具版本的 `is_destroyed`、`is_detached` 等属性在关闭**开始时**就会改变。必须核对实际版本语义，不能只看属性汇总 `cleanup_confirmed=true`。`flush()` 或固定 sleep 也不能替代异步完成证据。

如果任一步仍 pending，禁止把后续动作排到另一个线程“试试看”。记录未释放资源，保留唯一 owner；不能通过丢弃 future 假装没有在途操作。

## 回调与缓冲区的特殊风险

- 某些 hook 实现即使只有 `onEnter` 的对象形式，仍会创建包含返回路径的 listener；函数式入口探针是否不同，需按工具版本验证，不能推广为所有框架规律。
- 阻塞接收调用的 onLeave 可能很晚才触发；先评估能否在更高层完整报文边界取样，或只收提交侧数据再用独立验证补证据。
- 持久回调、对象、缓冲区与字符串需要明确所有权和存活时间。函数已返回不等于异步消费者不再使用这些对象。
- 任务在超时后可能仍返回：接住结果并用同一 owner 完成释放，不能让晚到成功值泄漏，也不能两次释放。

## 崩溃后按证据归因

停止新增附加/自动重试，先保全控制器事件、目标进程创建/退出时间、系统崩溃记录、故障模块/偏移及可获得的转储。原状态文件即使错误地写过“清理完成”也保留，另增审计纠正。

把三件事分开：

- **已观察**：目标在某时刻崩溃、某操作超时、某回调仍在途。
- **已确认缺陷**：控制器在旧操作未完成时并发发起了下一次清理。
- **尚未确定**：这个控制器缺陷是否导致该次崩溃；崩溃先于某动作时，不能把后来动作解释成最初原因。

成功请求与安全清理是两个验收项。清理改为串行后某次正常结束，仅证明这次生命周期完成，不证明旧崩溃根因已经解决。后续实验必须有新的可证伪假设与更小的观测范围。
