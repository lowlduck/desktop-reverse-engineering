# 桌面功能接口逆向

> 一句话：**别猜，去看；别一次改三个变量；别把「能跑一次」当交付。**

## 交付定义

| 等级 | 形态 | 验收核心 |
|---|---|---|
| T0 | 人工/工具完成一次 | 功能存在 + 前置条件 + 可核对的实际效果 |
| T1 | 不依赖目标客户端，独立协议或本地接口实现 | 停掉客户端仍成功；声明剩余服务依赖 |
| T2 | 客户端运行，直接调业务函数/内部服务 | 契约 + 状态 + ABI + 版本适配 |
| 非交付 | UI 自动化驱动 | 只能做基准与探针，不能当后端 |

T1 优先但不强求；T2 是正式交付选项，前提是契约与版本适配写清楚。CDP 调业务函数算 T2；通过 CDP 派发点击/UI 事件不算。

“不依赖页面”“不调用主进程”“不加载厂商库”“无需客户端获取/刷新材料”分别验证。若只完成了客户端运行期间的独立请求，报告这个范围，不宣称已通过停客户端的 T1 验收。不要为验证独立性擅自关闭用户应用。

「稳定 + 高复用」的可检验含义：换参数能跑、断了能恢复、别人拿到能调、长跑不崩、失败有错误码。

## 开工顺序

沿用用户已经给出的目标与授权，补齐影响执行的缺项即可；工具可用性或历史案例不提供额外授权。发送、刷新登录、修改客户端、关闭进程等动作按本次任务范围执行。用户只要求离线分析时，保持离线。

1. **建研究记录**（[模板](templates/research-record.md)）：功能、输入、**可独立确认的成功效果**、时间盒、测试环境。
2. **30 分钟侦察** → [02-observation-routing.md](references/02-observation-routing.md)：进程/命令行/模块依赖/日志/前端资源/壳特征。
3. **定位认证来源与生命周期** → [06-credentials-session.md](references/06-credentials-session.md)。仅采集目标操作需要的材料；可先做不依赖登录的静态与离线工作。
4. **判通道、抓一次完整调用**：按当前可见边界选择日志、页面/IPC、业务函数或网络观测点，保存有效长度与关联证据。
5. **还原参数** → [07-param-recovery.md](references/07-param-recovery.md)：前端三路径 + 信封假设 + 错误码分层。
6. **固化契约** → [03-protocol-contract.md](references/03-protocol-contract.md) + [接口契约模板](templates/interface-contract.md)。
7. **验收与交付** → [05-reliability-acceptance.md](references/05-reliability-acceptance.md) + [验证矩阵](templates/validation-matrix.md)。

工具怎么挑、怎么用（调试器 / hook / 反编译器 / 抓包各自的适用面与坑）见 [10-tooling.md](references/10-tooling.md)——**工具缩短定位，不替代决策**。

## 硬规则

1. **可证伪实验尽量一次只改一个变量**，记录对照与共同固定条件；必须联动的参数先明确契约，不把联合修复当作单因素因果证明。
2. **受理 ≠ 完成**。HTTP 200、入队或函数返回 true 不足以证明业务成功；读取必要业务码及结果/对象回显。异步或写操作再通过完成回执、查询或对端效果确认。
3. **观测点跟证据走**。已有明文日志是候选捷径，但不假定所有日志均明文或无保护；原生加密链路沿业务边界定位。
4. **壳先分类再决定**：压缩壳/加密壳可脱；虚拟化壳不破，改边界观察或「调而不破」。
5. **设时间盒和请求预算**，45 分钟/3 次失败可作起点，按任务调整。停止重复无新证据的尝试；区分“工具路线暂未成功”和“协议假设已被推翻”。
6. **大输出落盘，只读切片**。日志 → grep 关键词 → 读前后 60 行。禁止整读进上下文。
7. **结论带标签**：OBSERVED / HYPOTHESIS / VALIDATED / PARTIAL / REJECTED / UNTESTED + 版本 + 证据路径。
8. **材料绑定会话代次和来源**。仅在已验证范围复用；重登/撤销后旧材料不能自动沿用。必要冻结样本只保存在受控私有目录，不进入公开报告或 Git。
9. **请求元数据以实际契约为准**。记录 UA/Referer/Origin 等字段是否存在、类型与来源，不向无此语义的协议硬加浏览器请求头，也不凭头差异判定掉线原因。
10. **变更可回滚**：改文件前备份并记 sha256；交付带一键恢复与清理清单。

## 反模式（出现即不算交付）

- 坐标点击 / 截图识别 / 键鼠模拟 / DOM 事件派发 当后端。
- 重放带一次性 nonce 的完整抓包，换参数就废。
- 把「没抓到」当「不存在」；把「失败」当「有某种保护」。
- 只跑通一次就宣布稳定；换 uid 就失败还叫完成。
- 凭据过期靠人工重登，却在报告里写「已自动化」。
- 离线重建通过就发起批量请求；传输认证通过就忽略业务错误。
- 丢弃 pending future 并发 unload/detach，再用提前变化的状态属性宣称清理成功。
